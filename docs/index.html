SpaceMouse navigation for Godot 4

A free, open-source editor plugin that gives Godot reliable six-axis navigation with 3Dconnexion SpaceMouse devices on Windows.

Download v1.0.1 View source and documentation

Built for actual 3D work

  • Pan, orbit, fly, and zoom directly in Godot's 3D editor viewport.
  • Control selected Camera3D nodes and runtime cameras.
  • Raw-HID input works alongside 3DxWare and Blender.
  • Per-axis inversion, smoothing, deadzone, adaptive speed, and horizon lock.
  • Automatic hidden bridge startup and built-in diagnostics.

Install in three steps

  1. Copy addons/spacemouse_bridge into your Godot project.
  2. Run python_bridge/install_requirements.bat once.
  3. Enable SpaceMouse Bridge under Project Settings → Plugins.

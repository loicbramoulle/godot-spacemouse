# Contributing

Bug reports, device compatibility results, documentation fixes, and focused pull requests are welcome.

When reporting a device problem, include:

- Godot version
- Windows version
- SpaceMouse model
- 3DxWare version
- Python version
- Output from `addons/spacemouse_bridge/python_bridge/run_probe.bat`

Do not include passwords, tokens, private project files, or unrelated system information.
